# LearningPath — implementert produktkontrakt

LearningPath viser ti backend-eide produktmoduler. En økt inneholder opptil seks autoritativt valgte spørsmål og identifiseres med `sessionId`; hvert spørsmål identifiseres i frontend med `sessionQuestionId`. Backend eier rundeprofil, seed, repetisjonsgate, grading, persistens og mastery. Frontend eier presentasjon, lokal svarstate frem til submit, umiddelbar feedback og retry. Den offentlige toggelen aktiveres kun i P23.
